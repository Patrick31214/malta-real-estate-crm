STEP 1: Get Your Password from pgAdmin
---------------------------------------
1. Open pgAdmin 4
2. In the left panel, RIGHT-CLICK on your server
   (It's usually called "PostgreSQL 18" or "PostgreSQL 16")
3. Click "Properties"
4. Click the "Connection" tab at the top
5. Look at the "Password" field
6. THAT IS YOUR PASSWORD! (might show as dots ••••••)
7. If you can see it, copy it
   If you can't see it, you saved it when setting up pgAdmin

STEP 2: Update Your .env File
------------------------------
1. In Command Prompt, type:
   notepad .env

2. Find this line:
   DB_PASSWORD=

3. Add your password after the = sign:
   DB_PASSWORD=your_actual_password

   IMPORTANT: 
   - No quotes around the password
   - No spaces before or after
   - Just the password itself

4. Save the file (Ctrl+S)
5. Close Notepad

STEP 3: Start the Application
------------------------------
In Command Prompt, type:
   npm start

YOU SHOULD SEE:
✓ Database connection has been established successfully.
🚀 Server is running on http://localhost:5000
