═════════════════════════

Method A - Windows Services (Easiest):
--------------------------------------
1. Press: Windows Key + R
2. Type: services.msc
3. Press: Enter
4. Find: postgresql-x64-16 (or similar)
5. Right-click it
6. Click: Start

---------------------------------------------
1. Right-click Command Prompt
2. Click "Run as Administrator"
3. Type: net start postgresql-x64-16
4. Press Enter
