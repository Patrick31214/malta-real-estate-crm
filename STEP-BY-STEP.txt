WHY SOME LINKS DON'T WORK:
---------------------------
• START-CRM.bat     → This is the main launcher. Use this EVERY time.
• start-windows.bat → This builds the production version. It needs
                      PostgreSQL installed FIRST. If PostgreSQL is not
                      running, it will close immediately (this is normal).
• GET-LATEST.bat    → This needs Git installed. If Git is not installed
                      it will close immediately. Use DOWNLOAD-LATEST.bat
                      instead to get the latest code.
• All .bat files    → They CLOSE IMMEDIATELY if something is wrong.
                      Read the COMMON PROBLEMS section below if this happens.

THE RULE: Always use START-CRM.bat to open the CRM.
          If START-CRM.bat works, use that and nothing else.

══════════════════════════════════════════════════════════════════
STEP 1 – INSTALL REQUIRED SOFTWARE (FIRST TIME ONLY)
══════════════════════════════════════════════════════════════════

A) Install Node.js (Required)
   1. Go to: https://nodejs.org/
   2. Download the "LTS" version (the green button)
   3. Run the installer, click Next → Next → Install
   4. When finished, RESTART your computer

B) Install PostgreSQL (Required for the database)
   1. Go to: https://www.postgresql.org/download/windows/
   2. Click "Download the installer"
   3. Choose the latest version for Windows x86-64
   4. Run the installer:
      - Installation Directory: leave as default
      - Select Components: leave all checked
      - Data Directory: leave as default
      - Password: WRITE THIS DOWN! You will need it later.
        Example: MyPostgres2024!
      - Port: 5432 (leave as default)
      - Locale: leave as default
   5. Click Next → Next → Finish
   6. RESTART your computer after installation

══════════════════════════════════════════════════════════════════
STEP 2 – DOWNLOAD THE CRM FILES (FIRST TIME ONLY)
══════════════════════════════════════════════════════════════════

Option A – If you have Git installed:
   1. Open Command Prompt (Win+R → type cmd → press Enter)
   2. Navigate to where you want the files:
      Example: cd C:\Users\YourName\Desktop
   3. Run: git clone https://github.com/Patrick31214/malta-real-estate-crm.git
   4. Then: cd malta-real-estate-crm

Option B – Without Git (easier):
   1. Go to: https://github.com/Patrick31214/malta-real-estate-crm
   2. Click the green "<> Code" button
   3. Click "Download ZIP"
   4. RIGHT-CLICK the downloaded ZIP → "Extract All"
   5. Choose your desktop or a folder you can find easily
   6. Open the extracted folder "malta-real-estate-crm"

══════════════════════════════════════════════════════════════════
STEP 3 – CONFIGURE THE DATABASE PASSWORD
══════════════════════════════════════════════════════════════════

   1. Inside the malta-real-estate-crm folder, find the file ".env.example"
   2. RIGHT-CLICK on it → "Copy"
   3. RIGHT-CLICK on an empty area → "Paste"
   4. Rename the copy to ".env" (remove the ".example" part)
      Note: If Windows won't let you do this:
      - Open Notepad
      - Open the ".env.example" file from Notepad
      - Click File → Save As
      - In the filename box, type exactly: .env
      - Change "Save as type" to "All Files (*.*)"
      - Save in the malta-real-estate-crm folder
   5. Open ".env" in Notepad
   6. Find the line: DB_PASSWORD=your_password_here
   7. Change "your_password_here" to YOUR PostgreSQL password
      Example: DB_PASSWORD=MyPostgres2024!
   8. Also change the JWT secrets (optional but recommended for security):
      JWT_SECRET=any_long_random_text_here_at_least_32_characters
      JWT_REFRESH_SECRET=different_long_random_text_here
   9. Save the file (Ctrl+S) and close Notepad

══════════════════════════════════════════════════════════════════
STEP 4 – START THE CRM (EVERY TIME YOU WANT TO USE IT)
══════════════════════════════════════════════════════════════════

   1. Make sure PostgreSQL is running:
      - Press Win+R → type "services.msc" → press Enter
      - Find "postgresql-x64-xx" in the list
      - If Status is not "Running", right-click → Start

   2. Double-click START-CRM.bat in the malta-real-estate-crm folder
      - It will open TWO windows:
        Window 1 (this one): The backend API server
        Window 2: The frontend interface
      - Your browser will open automatically at http://localhost:3000
      - Wait about 15-20 seconds for everything to start

   3. If the browser doesn't open automatically:
      - Open your browser
      - Type: http://localhost:3000
      - Press Enter

STEP 5 – FIRST-TIME DATABASE SETUP
══════════════════════════════════════════════════════════════════

   The first time you start the CRM, you need to set up the database:

   1. Open Command Prompt in the CRM folder:
      - Hold Shift + Right-click on the malta-real-estate-crm folder
      - Click "Open PowerShell window here" or "Open Command Prompt here"

   2. Run these commands one at a time (wait for each to finish):
      npm install
      npm run db:create
      npm run db:migrate
      npm run db:seed

   3. This creates all the tables and adds sample data.

   4. Default admin login (from sample data):
      Email:    admin@maltarealestate.com
      Password: Password123!

      CHANGE THIS PASSWORD after first login!

COMMON PROBLEMS
══════════════════════════════════════════════════════════════════

PROBLEM: A .bat file opens and closes immediately
SOLUTION:
   1. Right-click the .bat file → "Edit" (opens in Notepad)
   2. Add "pause" at the very end of the file, save it
   3. Double-click it again — now you can read the error message
   4. Fix the error shown, then remove the "pause" line

PROBLEM: "PostgreSQL is NOT listening on port 5432"
SOLUTION:
   1. Press Win+R → type services.msc → press Enter
   2. Find "postgresql-x64-16" (or similar) in the list
   3. Right-click → Start
   4. Wait 5 seconds, then run START-CRM.bat again

PROBLEM: "DB_PASSWORD not set" or authentication failed
SOLUTION:
   1. Open .env in Notepad
   2. Find: DB_PASSWORD=
   3. Make sure it has your exact PostgreSQL password
   4. No spaces around the = sign
   5. Save and try again

PROBLEM: Browser shows "Cannot connect" or blank page
SOLUTION:
   1. Check that the backend window is open (the black window)
   2. If it shows an error, read it carefully
   3. Most common fix: check your .env file has correct DB_PASSWORD
   4. Try: http://localhost:3000 OR http://localhost:5000

PROBLEM: GET-LATEST.bat closes immediately
SOLUTION:
   Use DOWNLOAD-LATEST.bat instead — it doesn't require Git.

PROBLEM: start-windows.bat closes immediately
SOLUTION:
   This requires PostgreSQL. Check it's installed and running (see above).
   Then make sure .env has the correct DB_PASSWORD.
   Use START-CRM.bat instead for development mode.

PROBLEM: "npm is not recognized"
SOLUTION:
   Node.js is not installed or not in PATH.
   1. Download Node.js from https://nodejs.org/
   2. Install it (LTS version)
   3. RESTART your computer
   4. Try again

PROBLEM: Agent photos not showing
SOLUTION:
   Agent photos use URL links (not file uploads).
   When adding/editing an agent, paste the full URL of their photo.
   Example: https://example.com/agent-photo.jpg
   The photo must be publicly accessible on the internet.

ONLINE DEPLOYMENT (HOSTING ON THE INTERNET)
══════════════════════════════════════════════════════════════════

   To make the CRM and website accessible online:

   RECOMMENDED: Deploy to Railway.app or Render.com
   ------------------------------------------------
   1. Create account at https://railway.app or https://render.com
   2. Connect your GitHub repository
   3. Add environment variables (same as your .env file)
   4. For the database, add a PostgreSQL service in the same project
   5. Set NODE_ENV=production
   6. Build command: npm run client:build
   7. Start command: npm start
   8. Railway/Render will give you a URL like: https://yourapp.railway.app

   DOMAIN NAME:
   - Buy a domain from Namecheap, GoDaddy, etc.
   - Point it to your Railway/Render URL
   - The public listing website will be at: https://yourdomain.com/listings
