MALTA CRM - HOW TO START (STEP BY STEP)
=========================================

Do these steps IN ORDER, one at a time.


================================================================
QUICK START - USE index.html IN YOUR BROWSER
================================================================

  The easiest way to use the CRM from your browser:

  1. Open Windows Explorer (the yellow folder icon on your taskbar).

  2. Go to your CRM folder:
        C:\Users\USER\malta-crm\malta-real-estate-crm

  3. Double-click the file named:  index.html
     It opens in your browser and shows a friendly launch page.

  4. That page will tell you if the server is running or not,
     and has a big "OPEN THE CRM" button.

  5. If the server is not running, double-click start-windows.bat
     (in Windows Explorer), wait 20 seconds, then click
     "Check again" on the index.html page.

  NOTE: If you opened the folder URL in Edge (file:///C:\...) and
        saw a list of files, just click on index.html in that list.
        Edge will show the launch page.


================================================================
IMPORTANT - READ THIS FIRST
================================================================

  There are TWO different things that look similar but are NOT the same:

  [A] WINDOWS EXPLORER  = the yellow folder icon on your taskbar or desktop.
       This is where you see your files and folders.
       Its address bar shows a PATH like: C:\Users\YourName\...

  [B] WEB BROWSER  = Chrome, Edge, or Firefox.
       This opens websites. Its address bar shows web addresses like:
       https://www.google.com

  DO NOT type 'cmd' in your web browser - it will search Google.
  You must open Windows Explorer (the yellow folder), NOT your browser.


================================================================
ABOUT start-windows.bat  (PLEASE READ - this causes confusion)
================================================================

  start-windows.bat is a PROGRAM, not a website link.

  DO NOT try to open start-windows.bat in Chrome, Edge, or Firefox.
  Typing "http//start-windows.bat" or dragging it into a browser will NOT work.
  Opening it in Notepad will just show the script text - that is also wrong.

  HOW TO RUN IT CORRECTLY:
    Double-click start-windows.bat in Windows Explorer (the yellow folder).
    A black Command Prompt window will open and run the CRM.

  WHAT TO EXPECT:
    - A black window opens and shows text (this is NORMAL and CORRECT).
    - After about 15 seconds, your browser opens automatically.
    - The CRM website appears in your browser at http://localhost:3001
    - The black window stays open. THIS IS CORRECT - do not close it.
      The black window is the engine keeping the CRM running.
      Closing the black window will STOP the CRM.

  IF DOUBLE-CLICK OPENS NOTEPAD (shows lines of text starting with @echo):
    Right-click on start-windows.bat  (hold right mouse button, then release)
    Click "Open with"
    Click "Choose another app" (or "Choose default program")
    Scroll down and click "Windows Command Processor" or "cmd.exe"
    Make sure "Always use this app" is NOT ticked
    Click OK
    The black window should now open and start the CRM.
    OR: just use command prompt (see STEP 2 below).


================================================================
STEP 1 - OPEN A COMMAND PROMPT  (3 methods - use whichever works)
================================================================

  --- METHOD A: Windows key shortcut (EASIEST) ---

  1. Press the Windows key and R at the same time (Win+R).
     A small 'Run' box appears in the bottom-left corner of your screen.

  2. Type:  cmd
     Then click OK.
     A black window opens (Command Prompt).

  3. In the black window, type the following and press ENTER:
        cd C:\Users\YourName\malta-crm\malta-real-estate-crm
     IMPORTANT: Replace 'YourName' with YOUR actual Windows username.
     TIP: Your username is the word shown BEFORE the > in the black window.
          Example:  C:\Users\USER>     means your username is USER
          Example:  C:\Users\Patrick>  means your username is Patrick
     Choose the ONE line that matches YOUR username:
        cd C:\Users\USER\malta-crm\malta-real-estate-crm       (if your username is USER)
        cd C:\Users\Patrick\malta-crm\malta-real-estate-crm    (if your username is Patrick)
     Then press ENTER.

  4. Now type:  git pull
     Then press ENTER.
     Wait until it finishes (you will see 'Already up to date.' or a file list).

  5. Type:  exit  and press ENTER.  The black window closes.


  --- METHOD B: From Windows Explorer address bar ---

  NOTE: Windows Explorer is the YELLOW FOLDER icon - NOT your web browser.

  1. Open Windows Explorer (click the yellow folder icon on the taskbar).

  2. Navigate to your CRM folder:
        C:\Users\YourName\malta-crm\malta-real-estate-crm
     (Double-click folders to go inside them.)

  3. Look at the TOP of the Windows Explorer window.
     You will see a white bar showing the folder path (NOT a Google search bar).
     Example of what it looks like:  C:\Users\USER\malta-crm\...
     (USER is whatever name appears in your Command Prompt before the >)

  4. CLICK ONCE on that white path bar.
     The whole path turns blue/highlighted.

  5. With the path bar still highlighted (blue), type:  cmd
     Then press ENTER.
     A black Command Prompt window opens.

  6. In the black window, type:  git pull
     Then press ENTER.  Wait for it to finish.

  7. Type:  exit  and press ENTER.  The black window closes.


  --- METHOD C: Right-click inside the folder ---

  1. Open Windows Explorer and go to the CRM folder.

  2. Hold the SHIFT key on your keyboard.

  3. While holding SHIFT, RIGHT-CLICK on any empty space inside the folder
     (not on a file, just on blank space).

  4. A menu appears.  Click one of these options (whichever you see):
       - 'Open PowerShell window here'
       - 'Open command window here'
       - 'Open in Terminal'
     A black (or blue) window opens.

  5. In that window, type:  git pull
     Then press ENTER.  Wait for it to finish.


================================================================
STEP 2 - START THE CRM  (do this EVERY TIME you want to use it)
================================================================

  1. Open Windows Explorer (the yellow folder icon).

  2. Go to your CRM folder:
        C:\Users\YourName\malta-crm\malta-real-estate-crm

  3. Find the file named:  start-windows.bat
     (It is in the same folder as this STEP-BY-STEP.txt file.)

  4. DOUBLE-CLICK on  start-windows.bat
     A black window opens. This is CORRECT - it is not an error.
     (If it opens in Notepad instead, see the ABOUT section above.)

  5. The black window installs things and starts the CRM server.
     This can take 1-3 minutes the first time. Just wait.

  6. After about 15 seconds, your browser opens automatically and
     shows the CRM website at:
        http://localhost:3001

     If your browser does NOT open automatically:
     Open Chrome, Edge, or Firefox yourself and type in the address bar:
        http://localhost:3001
     Then press ENTER.

  IMPORTANT: The black window must stay open the whole time you use the CRM.
             The black window IS the CRM server - closing it stops everything.

  ALSO: If the CRM does not open after 30 seconds, something went wrong.
        Look at the black window for error messages.
        Common problems are listed below in COMMON PROBLEMS.


================================================================
STEP 3 - STOPPING THE CRM
================================================================

  1. Click on the black Command Prompt window running the CRM.
  2. Press Ctrl+C (hold Ctrl and press C at the same time).
  3. When asked 'Terminate batch job (Y/N)?', type  Y  and press ENTER.


================================================================
COMMON PROBLEMS
================================================================

  PROBLEM: I typed 'cmd' and it opened a Google search / showed search results
  SOLUTION: You typed 'cmd' in your WEB BROWSER address bar by mistake.
            Your web browser (Chrome, Edge, Firefox) is NOT Windows Explorer.
            Use METHOD A (Win+R) from STEP 1 above instead - it always works.

  PROBLEM: 'npm' is not recognized
  SOLUTION: Install Node.js. Go to https://nodejs.org/
            Download the version labelled 'LTS - Recommended For Most Users'.
            Run the installer and click Next until it finishes.
            After installing, close and re-open Windows Explorer, then try again.

  PROBLEM: 'git' is not recognized
  SOLUTION: Install Git. Go to https://git-scm.com/download/win
            Click 'Download for Windows', run the installer, click Next everywhere.
            After installing, close and re-open any black windows, then try again.

  PROBLEM: Double-clicking start-windows.bat opens Notepad with text starting
           with @echo off (instead of opening a black window)
  SOLUTION: See "IF DOUBLE-CLICK OPENS NOTEPAD" in the ABOUT section above.
            Or: open a Command Prompt (METHOD A from STEP 1), navigate to
            the CRM folder, and type:  start-windows.bat  then press ENTER.

  PROBLEM: I opened start-windows.bat in Chrome / Edge / Firefox / a browser
  SOLUTION: start-windows.bat is NOT a website. You cannot open it in a browser.
            Double-click it in Windows Explorer (the yellow folder icon).
            A black Command Prompt window will open - that is the CRM running.

  PROBLEM: The black window closes immediately / shows an error
  SOLUTION: Make sure you double-clicked start-windows.bat from INSIDE the folder:
               C:\Users\YourName\malta-crm\malta-real-estate-crm
            (This folder must contain a file called package.json)

  PROBLEM: Browser shows 'This site can't be reached' or connection refused
  SOLUTION: Wait 30 seconds after double-clicking start-windows.bat,
            then try http://localhost:3001 again.


================================================================
NEED TO UPDATE TO A NEW VERSION?
================================================================

  1. Follow STEP 1 again (open a black Command Prompt window, type: git pull).
  2. Then follow STEP 2 again (double-click start-windows.bat).
