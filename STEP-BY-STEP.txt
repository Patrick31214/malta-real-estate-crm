MALTA CRM - HOW TO START (STEP BY STEP)
=========================================

Do these steps IN ORDER, one at a time.


================================================================
WHAT IS THE MALTA CRM? — READ THIS FIRST IF YOU ARE A BEGINNER
================================================================

  The Malta Real Estate CRM is a PRIVATE WEB APPLICATION that runs
  entirely on YOUR OWN COMPUTER.

  It is NOT a WordPress plugin.
  It is NOT something you paste into WordPress Elementor.
  It is NOT hosted on the internet.

  WHAT IT IS:
    - A private website that runs only on your computer.
    - You access it by typing  http://localhost:3001  in your browser.
    - It has a Login Page (email + password) to keep it secure.
    - After login, you see a Dashboard to manage your properties and owners.

  HOW IT WORKS (two parts):
    Part 1 — The ENGINE (backend):  start-windows.bat starts this.
             This is a program running in a black window.
             It also builds the CRM website on first run (takes 2-3 minutes).
    Part 2 — THE WEBSITE (frontend):  built automatically by start-windows.bat.
             After Part 1 is running, open http://localhost:3001 to use the CRM.

  THE ONLY THING YOU NEED TO DO IS:
    Double-click  start-windows.bat  in Windows Explorer.
    Then wait about 2-3 minutes (first run only).
    Your browser will open the CRM Login Page automatically.
    Type your email and password, click Sign In — you're in!

  ABOUT index.html (the helper page):
    index.html is a STATUS CHECKER. It tells you if the server is running
    and has a button to open the CRM login page. You can open it directly
    by double-clicking it in Windows Explorer.
    DO NOT copy its code into WordPress — it won't work there.

  ABOUT WordPress:
    This CRM does not need WordPress to work.
    The CRM runs completely separately from WordPress.
    If you want to later connect it to WordPress, that is a future step —
    but for now, just use it at http://localhost:3001 directly in your browser.

     You will see a LOGIN PAGE with an Email and Password form.

     - If you set up your own account:  use your email and password.
     - If you loaded sample/demo data:
         Email:    admin@maltarealestate.com

     properties, owners, and more.

  NOTE: Keep the black window open while you use the CRM.
        Closing it stops the server and the CRM stops working.

  TIP: You can also double-click index.html to open a helper page
       that shows whether the server is running and has a
       "OPEN THE CRM LOGIN PAGE" button.

ABOUT start-windows.bat  (PLEASE READ - this causes confusion)
================================================================

  start-windows.bat is a PROGRAM, not a website link.

  DO NOT try to open start-windows.bat in Chrome, Edge, or Firefox.
  Typing "http//start-windows.bat" or dragging it into a browser will NOT work.
  Opening it in Notepad will just show the script text - that is also wrong.

  HOW TO RUN IT CORRECTLY:
    Double-click start-windows.bat in Windows Explorer (the yellow folder).
    A black Command Prompt window will open and run the CRM.

  WHAT TO EXPECT — TWO windows will open, not one:

  WINDOW 1 — "SETUP WINDOW" (the first window that appears):
    - Shows progress messages like [1/4], [2/4], [3/4], [4/4].
    - FIRST TIME ONLY: step [3/4] says "Building CRM interface pages..."
      This takes 2-3 minutes. Do NOT close the window — just wait.
    - After step [4/4], it shows "YOUR CRM IS NOW STARTING UP!" and the URL.
    - This window then says "Press any key to close THIS setup window."
      When you press a key THIS setup window closes. That is fine.
      The CRM keeps running in Window 2.

  WINDOW 2 — "Malta CRM Server - DO NOT CLOSE" (opens during step 4):
    - A second black window opens with the title:
        Malta CRM Server - DO NOT CLOSE
    - This window is the ENGINE running your CRM.
    - KEEP THIS WINDOW OPEN the whole time you use the CRM.
    - If you close this window, the CRM stops.

  BROWSER:
    - About 8 seconds after step [4/4], your browser opens at:
        http://localhost:3001
    - You will see a LOGIN PAGE with Email and Password boxes.

  IF YOU SEE RAW JSON TEXT IN THE BROWSER (not a login form):
    The React pages did not build correctly.  How to fix:
      1. Close BOTH black windows.
      2. Check Node.js version: open a Command Prompt and type  node --version
         You need v16 or newer. Download from https://nodejs.org/ if older.
      3. Delete the folder: client\node_modules (if it exists).
      4. Double-click start-windows.bat again and wait for the build.
      If the error continues, copy the red error text and ask for help.

  IF YOU PRESSED "ANY KEY" AND THE WINDOW CLOSED:
    You probably pressed a key on the SETUP WINDOW (Window 1).
    That is OK — closing Window 1 does NOT stop the CRM.
    Look for the second window titled "Malta CRM Server - DO NOT CLOSE".
    If that window is also closed, just double-click start-windows.bat again.

  IF DOUBLE-CLICK OPENS NOTEPAD (shows lines of text starting with @echo):
    Right-click on start-windows.bat  (hold right mouse button, then release)
    Click "Open with"
    Click "Choose another app" (or "Choose default program")
    Scroll down and click "Windows Command Processor" or "cmd.exe"
    Make sure "Always use this app" is NOT ticked
    Click OK
    The black window should now open and start the CRM.
    OR: just use command prompt (see STEP 2 below).

FILES IN THIS FOLDER - WHAT EACH ONE DOES
================================================================

  You will see several files in the malta-real-estate-crm folder.
  Here is what each one is for:

  start-windows.bat
    ✔ THE MAIN FILE YOU NEED.
    Double-click this to START the CRM.

    ✔ ALSO WORKS AS A STARTER - use this if start-windows.bat is not present.

  quick-start.sh
    ⚠ FOR MAC AND LINUX ONLY — DO NOT USE ON WINDOWS.
    This file has a .sh extension which means it is a "shell script"

    IGNORE THIS FILE. Windows users use quick-start.bat instead.

    Older shortcuts that also start the CRM. If start-windows.bat works,

    the CRM server is running and has a button to open the Login Page.
    DO NOT paste its code into WordPress.

  STEP-BY-STEP.txt
    This file. Full beginner guide.

  .env / .env.example
    Configuration files with your database password and security keys.
    .env is your actual config. .env.example is the template.
    These files are hidden in Windows Explorer by default.

COMMON PROBLEMS
================================================================

  PROBLEM: The black window closes IMMEDIATELY (opens and closes in a flash)
           - I double-clicked the file and the window disappeared before I
             could read anything
  SOLUTION: This nearly always means ONE of these things:

    CAUSE A — You are running the script from INSIDE a ZIP archive.
              ZIP archives look exactly like normal folders in Windows Explorer
              but the files inside them are NOT actually extracted to your PC.
              When you run a script from inside a ZIP, Windows puts it in a
              hidden temporary folder where package.json does not exist, so
              the script fails in the first second and the window closes.

              HOW TO FIX:
                1. CLOSE the ZIP window completely.
                2. Find the ZIP file (e.g. malta-real-estate-crm.zip) in
                   Windows Explorer (the yellow folder icon).
                3. RIGHT-CLICK on the ZIP file.
                4. Click "Extract All..." (or "Extract Here").
                5. Choose a folder and click Extract.
                6. A NEW real folder appears (not a ZIP).
                7. Open that new folder.
                8. Double-click quick-start.bat from INSIDE that real folder.

    CAUSE B — Node.js is not installed on your computer.
              The CRM needs Node.js to run. If it is missing, the script
              exits with nothing visible.

              HOW TO FIX:
                1. Open your browser and go to: https://nodejs.org/
                2. Click the big green "LTS" button and download.
                3. Run the installer - click Next on everything.
                4. RESTART your computer.
                5. Double-click quick-start.bat again.

    CAUSE C — You moved quick-start.bat out of the project folder.
              The script must be inside the malta-real-estate-crm folder
              (the same folder that contains package.json).

              HOW TO FIX:
                Find the malta-real-estate-crm folder and double-click
                quick-start.bat (or start-windows.bat) from INSIDE it.

  PROBLEM: I typed 'cmd' and it opened a Google search / showed search results
  SOLUTION: You typed 'cmd' in your WEB BROWSER address bar by mistake.
            Your web browser (Chrome, Edge, Firefox) is NOT Windows Explorer.
            Use METHOD A (Win+R) from STEP 1 above instead - it always works.

  PROBLEM: 'npm' is not recognized
  SOLUTION: Install Node.js. Go to https://nodejs.org/
            Download the version labelled 'LTS - Recommended For Most Users'.
            Run the installer and click Next until it finishes.
            After installing, close and re-open Windows Explorer, then try again.

  PROBLEM: 'git' is not recognized
  SOLUTION: Install Git. Go to https://git-scm.com/download/win
            Click 'Download for Windows', run the installer, click Next everywhere.
            After installing, close and re-open any black windows, then try again.

  PROBLEM: The black window closed after I pressed "Press any key to continue"
           and now nothing is running / the browser shows nothing
  SOLUTION: You pressed a key on the SETUP WINDOW (Window 1).  That is OK.
            Pressing a key on Window 1 only closes the setup window.
            The CRM SHOULD keep running in a SECOND window titled:
               "Malta CRM Server - DO NOT CLOSE"
            Look on your Taskbar at the bottom of the screen for that window.
            Click on it to bring it to the front.
            If BOTH windows closed, double-click start-windows.bat again —
            the setup takes only a few seconds the second time.

  PROBLEM: Double-clicking start-windows.bat opens Notepad with text starting
           with @echo off (instead of opening a black window)
  SOLUTION: See "IF DOUBLE-CLICK OPENS NOTEPAD" in the ABOUT section above.
            Or: open a Command Prompt (METHOD A from STEP 1), navigate to
            the CRM folder, and type:  start-windows.bat  then press ENTER.

  PROBLEM: I opened start-windows.bat in Chrome / Edge / Firefox / a browser
  SOLUTION: start-windows.bat is NOT a website. You cannot open it in a browser.
            Double-click it in Windows Explorer (the yellow folder icon).
            A black Command Prompt window will open - that is the CRM running.

  PROBLEM: The black window closes immediately / shows an error
  SOLUTION: See the detailed entry at the top of COMMON PROBLEMS above.
            The most common cause is running the script from inside a ZIP
            archive without extracting it first. Extract the ZIP, then
            double-click quick-start.bat from inside the extracted folder.

  PROBLEM: The "Malta CRM Server" window opens and closes immediately
           (or: the server crashes right after the setup window closes)
  SOLUTION: The server is failing to connect to the database. This happens
            when PostgreSQL is not running OR your DB_PASSWORD in .env is wrong.

    STEP A — Check your .env file:
      1. Open ".env" in Notepad.
      2. Find the line: DB_PASSWORD=
         If it still says  DB_PASSWORD=your_password_here  then you have NOT
         set your PostgreSQL password yet.  Replace "your_password_here" with
         the actual password you chose when you installed PostgreSQL.
      3. Save the file.
      4. Double-click start-windows.bat again.

    STEP B — Make sure PostgreSQL is running:
      1. Press Win+R (hold Windows key, press R).
      2. Type:  services.msc  and press ENTER.
      3. Scroll down and find a service named "PostgreSQL" (may include a version
         number, e.g. "postgresql-x64-15").
      4. If its Status column says "Running" — good, skip to STEP C.
      5. If Status is empty or "Stopped":
         - Right-click the service name.
         - Click "Start".
         - Wait 5 seconds.
      6. Double-click start-windows.bat again.

    STEP C — Install PostgreSQL if you have not done so yet:
      1. Download from: https://www.postgresql.org/download/windows/
      2. Run the installer. WRITE DOWN the password you set.
      3. When installation finishes, RESTART your computer.
      4. Open ".env" in Notepad and set:  DB_PASSWORD=<your chosen password>
      5. Double-click start-windows.bat again.

    HOW TO READ THE ERROR:
      After all setup steps finish, a second black window titled
      "Malta CRM Server - DO NOT CLOSE" opens.
      If the server crashes, that window shows the reason, for example:
        "Unable to connect to the database: password authentication failed"
        → wrong DB_PASSWORD in .env
        "Unable to connect to the database: connect ECONNREFUSED 127.0.0.1:5432"
        → PostgreSQL service is not running
        "Could not create/verify the database: password authentication failed"
        → wrong DB_PASSWORD in .env (caught BEFORE the server starts)
      Read the message and follow STEP A or STEP B above.

  PROBLEM: Setup says "[X] Could not create or verify the CRM database"
  SOLUTION: This new check runs before the server starts to create the
            'malta_crm' database automatically.  If it fails, the most
            common cause is a wrong DB_PASSWORD.

    1. Open ".env" in Notepad.
    2. Find the line:  DB_PASSWORD=
       The value after = must be EXACTLY the password you chose when
       you installed PostgreSQL.  It is case-sensitive.
    3. Also check:  DB_USER=postgres  (leave this as "postgres").
    4. Save the file and double-click start-windows.bat again.

    FORGOTTEN YOUR PostgreSQL PASSWORD?
    You can reset it via pgAdmin (the purple elephant icon in your
    Start Menu), or reinstall PostgreSQL (your data will be lost).

  PROBLEM: Browser shows 'This site can't be reached' or connection refused
  SOLUTION: Wait 30 seconds after double-clicking start-windows.bat,
            then try http://localhost:3001 again.

  PROBLEM: I changed DB_PORT or DB_PASSWORD in .env and now the CRM won't start
  SOLUTION: Change them BACK to the original values.

    The PostgreSQL service uses a fixed port (5432 by default) and a fixed
    password that you set during installation.  Changing DB_PORT or DB_PASSWORD
    in .env does NOT change what PostgreSQL listens on — it only tells the CRM
    which port and password to USE when connecting.

    If you changed DB_PORT to something other than 5432, the CRM tries to
    connect to a port where nothing is listening, and the connection fails.

    HOW TO FIX:
      1. Open ".env" in Notepad.
      2. Set:  DB_PORT=5432           (the standard PostgreSQL port)
      3. Set:  DB_PASSWORD=<the password you chose when you installed PostgreSQL>
      4. Save ".env" and double-click start-windows.bat again.

    If you have also changed the DB_PORT inside PostgreSQL itself (by editing
    postgresql.conf), change it back to 5432 and restart the PostgreSQL service.

  PROBLEM: My folder path shows "malta-crm\malta-real-estate-crm" — is that correct?
  SOLUTION: Yes, that path is perfectly fine.

    The project folder is named "malta-real-estate-crm" and it can live inside
    any parent folder you like (e.g., "malta-crm", "Documents", "Desktop").
    The setup scripts use %~dp0 which means "the folder this script lives in",
    so the parent folder name does not affect anything.

  PROBLEM: Is CLIENT_URL=http://localhost:3000 in .env correct?
  SOLUTION: Yes — leave it as http://localhost:3000.

    CLIENT_URL is used in development mode only (when you use START-CRM.bat or
    run npm run dev).  In that mode the React frontend runs on port 3000, and
    CLIENT_URL tells the backend which origin to allow for cross-origin requests.

    In production mode (start-windows.bat), the React pages are served by the
    same Express server on port 3001, so CLIENT_URL is not needed and the value
    in .env does not matter for that mode.

    Leave CLIENT_URL=http://localhost:3000 unchanged.

  PROBLEM: The backend window shows "password authentication failed for user postgres"
           and keeps crashing / restarting in a loop
  SOLUTION: The DB_PASSWORD in your .env file does not match your PostgreSQL password.

    STEP 1 — Open .env in Notepad:
      1. Open Windows Explorer (the yellow folder icon).
      2. Go to your CRM folder:
            C:\Users\YourName\malta-crm\malta-real-estate-crm
      3. You may not see .env because it is a hidden file.
         HOW TO SHOW HIDDEN FILES:
           - Click "View" in the top menu of Windows Explorer.
           - Tick "Hidden items" (or turn on "Show hidden items").
         Now .env should appear.
      4. Right-click on ".env" and choose "Open with" → Notepad.

    STEP 2 — Fix the password:
      5. Find the line that says:   DB_PASSWORD=
         The value after = should be exactly the password you chose when
         you installed PostgreSQL.
         Example:  DB_PASSWORD=MyPostgresPass123
      6. If it still says  DB_PASSWORD=your_password_here  you have NOT
         set it yet. Replace "your_password_here" with your actual password.
      7. Save the file (Ctrl+S) and close Notepad.
      8. Double-click start-windows.bat (or START-CRM.bat) again.

    FORGOTTEN YOUR PostgreSQL PASSWORD?
      Option A — Reset via pgAdmin:
        1. Open pgAdmin (the purple elephant icon in your Start Menu or
           in Windows Explorer under C:\Program Files\PostgreSQL\...).
        2. Expand "Servers" → "PostgreSQL" → right-click → Properties.
        3. Change the password and click Save.
        4. Update DB_PASSWORD in .env to match the new password.
      Option B — Reinstall PostgreSQL:
        WARNING: Reinstalling will DELETE ALL your database data.
        Only do this if you have no important data yet.
        1. Uninstall PostgreSQL via Windows Settings → Apps.
        2. Re-download from: https://www.postgresql.org/download/windows/
        3. Install it again. WRITE DOWN the new password.
        4. Update DB_PASSWORD in .env with the new password.

  PROBLEM: I can see the login page at http://localhost:3000 but I do not know
           what email and password to use
  SOLUTION: You need to create your first admin account.

    The CRM does not come with a pre-made account. You must create one.
    There are TWO ways to do this:

    ── METHOD 1: Create your own admin account (RECOMMENDED) ────────────────
    Use this if you want to choose your own email and password.

    Requirements: the backend must be running WITHOUT errors.
    (Start it with start-windows.bat OR fix the DB_PASSWORD error first.)

    Once the backend is running:
      1. Open a NEW Command Prompt window:
         Press Win+R, type cmd, click OK.
      2. Type the following and press ENTER:
            cd C:\Users\YourName\malta-crm\malta-real-estate-crm
         (Replace YourName with your Windows username.)
      3. Type this and press ENTER:
            npm run setup:admin
      4. Follow the prompts — enter your name, email, and a password
         (minimum 8 characters).
      5. Go back to http://localhost:3000 (or http://localhost:3001) and
         log in with the email and password you just entered.

    ── METHOD 2: Load sample/demo data ──────────────────────────────────────
    Use this if you want example properties, owners, and users already filled in
    so you can see how the CRM looks with data.

    Requirements: backend must be running, AND migrations must have run.

    Steps:
      1. Open a Command Prompt in the CRM folder (as in Method 1 step 1-2).
      2. Run migrations first (creates the database tables):
            npm run db:migrate
      3. Run the seeders (loads the sample data):
            npm run db:seed
      4. Log in at http://localhost:3000 (or http://localhost:3001) with:
            Email:    admin@maltarealestate.com
            Password: Password123!
         IMPORTANT: These are public demo credentials. Change the password
         immediately after your first login (use the profile/settings page,
         or delete this user and create a new one via npm run setup:admin).

    NOTE: Sample data includes example properties and owners for Malta.
    You can delete it later via the CRM interface.

  PROBLEM: I used START-CRM.bat and it opens TWO windows — which one is the server?
  SOLUTION: Both windows are needed:

    START-CRM.bat is the DEVELOPMENT MODE launcher. It opens:

    WINDOW 1 (the first window that appeared):
      Title: just "C:\Windows\..." or "malta-real-estate-crm"
      This runs the BACKEND (Node.js/Express API server) using nodemon.
      It will show messages like:
          ✓ PostgreSQL database connection established successfully.
          ✓ Server is running on port 3001
      KEEP THIS WINDOW OPEN — closing it stops the backend.
      If it shows errors (like password authentication failed), read the

    WINDOW 2 (opened automatically by Window 1):
      Title: "Malta CRM - Frontend"
      This runs the FRONTEND (React/Vite development server) on port 3000.
      It will show:
          VITE v5.x.x  ready in ... ms
          Local:   http://localhost:3000/
      KEEP THIS WINDOW OPEN — closing it stops the frontend.

    BROWSER: Open http://localhost:3000 to use the CRM in development mode.

    NOTE: start-windows.bat is a different launcher for PRODUCTION mode.
      - It builds the React pages once and serves everything on port 3001.
      - Use start-windows.bat for everyday use (one window, not two).
